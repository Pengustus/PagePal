## За проекта

**PagePal** е многослойна уеб система, разработена с **ASP.NET Core MVC (.NET 8)** и **MS SQL Server**, предназначена за автоматизиране на процесите в съвременната библиотека. Системата разделя библиографските заглавия от отделните физически екземпляри (чрез уникални инвентарни номера) и автоматизира заемането, връщането, изчисляването на санкции при просрочие и управлението на справедливи изчакващи опашки (FIFO).

---

## Планирани функционалности

### Читател (`Reader`)
* Регистрация, вход и управление на потребителски профил.
* Търсене и филтриране в каталога по заглавие, автор, жанр и актуална наличност.
* Заявяване на свободен екземпляр или включване в подредена изчакваща опашка при изчерпана наличност (с видимост на текущата позиция).
* Преглед на активни заеми, история на заеманията, срокове за получаване на резервирани книги, начислени санкции и системни известия.

### Библиотекар (`Librarian`)
* Добавяне, редактиране и архивиране на заглавия и физически екземпляри с уникални инвентарни номера и статус (*Наличен*, *Зает*, *Резервиран*, *Повреден/Изгубен*).
* Обработка на заемане и връщане на книги с автоматична защита срещу двойно заемане и проверка на лимитите.
* Автоматично пренасочване на върнат екземпляр към първия чакащ в опашката със срок за получаване и известяване.
* Генериране на справки за активни заеми, просрочени книги и най-търсени заглавия.

### Администратор (`Admin`)
* Управление на потребителски акаунти и разпределяне на роли (`Reader`, `Librarian`, `Admin`).
* Конфигуриране на библиотечните правила (максимален брой едновременни заеми, срок за заемане, срок за вземане на резервирана книга, дневна санкция при просрочие).
* Пълен достъп до всички справки и системни настройки.

## Архитектура на решението

Проектът е организиран в многослойна архитектура с ясно разделение на отговорностите и приложени шаблони за дизайн (**Repository / Unit of Work** и **State Pattern**):

```text
PagePal/
├── PagePal.Web/        # Презентационен слой (ASP.NET Core MVC, Controllers, Razor Views, ViewModels)
├── PagePal.Services/   # Слой бизнес логика (заемане, FIFO опашки, санкции, известия, справки)
├── PagePal.Data/       # Слой за достъп до данни (EF Core Code First, Entities, Migrations, Repositories)
└── PagePal.Tests/      # Автоматизирани тестове (xUnit, Moq, Coverlet — цел >= 65% покритие)
```

## Технологичен стек

* **Backend:** C#, ASP.NET Core MVC (.NET 8), ASP.NET Core Identity
* **База данни:** MS SQL Server, Entity Framework Core Code First (Migrations & Seeding)
* **Frontend:** HTML5, CSS3, Bootstrap 5, JavaScript (ES6+)
* **Сигурност и конфигурация:** .NET User Secrets, защитени сесийни бисквитки, защита срещу CSRF, XSS и SQL Injection
* **Тестване и CI/CD:** xUnit, Moq, Coverlet, GitHub Actions

## Локално стартиране (за разработка)

1. Клонирайте хранилището:
   ```bash
   git clone https://github.com/Pengustus/PagePal.git
   cd PagePal
   ```
2. Конфигурирайте връзката към базата данни чрез .NET User Secrets в проекта `PagePal.Web`:
   ```bash
   dotnet user-secrets init --project PagePal.Web
   dotnet user-secrets set "ConnectionStrings:DefaultConnection" "Server=(localdb)\\mssqllocaldb;Database=PagePalDb;Trusted_Connection=True;MultipleActiveResultSets=true" --project PagePal.Web
   ```
3. Приложете миграциите на базата данни:
   ```bash
   dotnet ef database update --project PagePal.Data --startup-project PagePal.Web
   ```
4. Стартирайте приложението:
   ```bash
   dotnet run --project PagePal.Web
   ```
